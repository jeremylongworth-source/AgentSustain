# Contributing

AgentSustain's original project material is licensed under [MIT](LICENSE), matching the owner's collection decision. Contributions must be material you have permission to contribute. No separate contributor licence agreement, ownership transfer, response-time promise or merge commitment is established here. Third-party source/standard rights remain separate; the project license does not relicense them.

Follow ROADMAP.md and the architecture gate in docs/architecture-review.md. Foundation proposals are welcome; individual skills require the architecture pack's explicit approval. Use atomic names, common contracts, traceable sources and fictional fixtures. Include narrow validation and describe uncovered behavior. Do not reproduce licensed standards or confidential data.

For source updates record official locator, version, effective interval, retrieval date, affected mappings and regression scenarios. Submit bounded proposals through pull requests with actual validation results and remaining limitations. Use [SECURITY.md](SECURITY.md) for the selected GitHub private-reporting route; never submit secrets or sensitive security details in a public issue or pull request. Owner approval is still required for governance and consequential publication actions. This document authorizes no publication or release.
