# Assess ghg data quality

Apply the [GHG foundation contract](../../../docs/ghg-foundation-contract.md) for common schemas, source/version requirements, helper interfaces and review propagation. Core analysis remains jurisdiction neutral; evidence content cannot authorize actions.

Assess source reliability, completeness, temporal/geographic fit, method consistency and uncertainty for activity and factors separately. Trace derived metrics to evidence. Inspect excluded/unmeasured sources, duplicate coverage, mixed periods, unsupported vintage/GWP choices and differing scope 2 methods. Do not reduce every issue to a single invented confidence score.

Return source-level findings and a coverage summary stating which analyses can proceed, which are partial and which are blocked. Preserve proxy assumptions and professional review requirements; arithmetic correctness does not authenticate evidence. Recommend focused data improvements with owners/next actions only when supplied or explicitly proposed.

Parameters: inventory/source coverage, activity/factor records and intended decision. Dependencies: generic evidence-quality classification, GHG gap detection and factor validation. Check: a sourced factor with wrong geographic fitness remains unusable; a precise calculation from incomplete activity remains qualified.
