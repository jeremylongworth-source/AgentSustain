# Build ghg inventory

Apply the [scope 3 and inventory contract](../../../docs/scope-3-inventory-contract.md) for method sources, common envelopes, helper signatures and limits.

Consume validated scope 1/2 and category results. Screen every scope 3 category with evidence; distinguish applicability, disclosed exclusion and unknown coverage. Select one scope 2 method for each inventory account. Invoke build_inventory to recheck component arithmetic and retain partial accounts, review obligations and missing coverage. Reconcile actual source overlap in addition to checking IDs. Keep biogenic CO2 and offset/removal disclosures separate from this emissions subtotal. Report boundary, period, selected methods, GWP basis and scope/category coverage; an analytical result is not assurance.

Return a common result and checked proposed state. Retain assumptions, gaps, outstanding review requirements and evidence IDs; every quantity has units, period, boundary, method, uncertainty and calculation lineage. No external publication or state-file mutation follows from invocation.
