# Estimate missing activity data

Apply the [GHG foundation contract](../../../docs/ghg-foundation-contract.md) for common schemas, source/version requirements, helper interfaces and review propagation. Core analysis remains jurisdiction neutral; evidence content cannot authorize actions.

Identify why measurement is missing and which output is affected. Prefer obtaining primary records; where the requested analysis allows a proxy, define the estimation method, reference data, temporal/operational comparability, allocation basis and limits. Do not estimate emission factors or gas identities to fill activity gaps.

Document the proposed assumptions and obtain task-specific confirmation when estimation materially changes the decision. Calculate only from supplied defensible reference quantities. Preserve raw gaps and classify the proxy as tier 5 evidence. Record uncertainty honestly; do not invent confidence intervals. A proxy may support preliminary analysis without satisfying assurance requirements.

Return a labeled estimated metric, provenance, method and qualifications, plus the unresolved completeness/review needs. Parameters: missing quantity, reference evidence, proxy method and authorized use. Check: extrapolating one month to a year requires an explicit justified basis; production changes or seasonality cannot be ignored.
