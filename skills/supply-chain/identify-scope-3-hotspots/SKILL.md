# Identify scope 3 hotspots

Apply the [supplier execution contract](../../../docs/supplier-contract.md) for supported helpers and evidence boundaries.

Use the existing selected inventory hotspot helper for category contributions and their actual denominator. Supplier-level attribution additionally requires sourced purchase/allocation links. Preserve omitted categories, mixed methods and data quality; spend alone is not a measured emissions hotspot.

Return a common result and checked proposal with source provenance, explicit assumptions, gaps and all open reviews. Quantities retain units, period, boundary and lineage. Instruction workflows require substantive source analysis; packaging and replay do not establish independent reasoning. No supplier-state overwrite, certification, external message or procurement action follows from analytical completion.

For supplier/category views of mapped purchases, use `identify-scope-3-hotspots` with existing mapping result IDs, a sourced hotspot review and an explicit percentage threshold. Each mapping is reproduced under current source inputs; fixture permission is opt-in again. Duplicate components/purchase lines and mixed GWP bases reject the denominator. Supplier and category views partition the same selected subtotal and cannot be added. Ties share a contribution group; zero subtotals have no percentage or hotspot. Full Scope 3 coverage remains unverified, and source uncertainty can change point-value ordering.
