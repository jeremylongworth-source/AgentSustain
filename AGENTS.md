Preserve evidence, units, boundaries, periods, assumptions, uncertainty, and all outstanding review requirements across workflows. Never derive emission factors from model memory. Missing defensible factors must produce EMISSION_FACTOR_REQUIRED.

Core skills must remain jurisdiction and vendor neutral. Versioned framework and jurisdiction modules reference primary sources; applicability screening is not a legal determination. Use fictional data in checked-in examples and tests. Do not publish, push, merge, release, deploy, or contact third parties without explicit authorization.

For foundation changes run the README architecture validation command. Add domain known-answer and adversarial checks with implemented capabilities; do not claim v1 readiness from architecture tests. Keep status and review evidence accurate.
