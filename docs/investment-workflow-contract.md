# Investment specialist contract

`investment-workflow-0.1.0` composes all thirteen existing finance operations with unchanged `run_finance` dispatch and calculations. The draft specialist is `sustainability-business-case`; its interface follows approved cd0c991 and awaits separate scoped owner review.

The common input envelope contains `contract_version`, `skill`, `state` and `parameters`. Parameters are exactly `steps`, `outputs`, `workflow_review`, `result_id`. Each step is exactly `skill`, the existing helper's `parameters`, and distinct `depends_on` result IDs. Fresh step and aggregate IDs, a resolvable acyclic graph and requested output selections are mandatory. Business-case steps accept either the existing cash-flow construction fields or the full `ranking_result_id`, `case_review`, `analysis_review`, `result_id` interface; these capabilities remain distinct.

`workflow_review` is exactly `boundary_id`, `period`, `evidence_ids`, `scope`, `reviewer_role`, `rationale`, `coverage_complete`, matched to the current state and attributed known evidence. It is a declaration, not authentication or approval. Helper source and financial reviews remain authoritative.

Dependency collection reads typed financial result/metric selectors, including NPV inputs, line quantities, project measures, ranking and sensitivity sources. Evidence IDs, source-context records, project IDs and prose are not instructions or source-producing dependencies. Fresh result references require explicit ancestors before execution; produced metric ownership is checked against actual results when encountered, without predicting output names. Missing sources remain blocked by the core helper. Runtime input failures remain visible blocked results; invalid recipe graphs produce no candidate. Blocked prerequisites stop dependent invocation; supported independent branches continue.

Full original helper results stay in candidate state, with SHA-256 references over sorted-key JSON UTF-8 serialization. The specialist adds no aggregate metric or portfolio total. Original state is unchanged; candidate revision is original plus one after atomic composition, with evidence/factors/units/periods/assumptions/uncertainty/gaps/reviews preserved. A professional finance/engineering review remains open. Incomplete coverage and partial/blocked source statuses stay qualified; all blocked steps make the aggregate blocked. Missing-factor diagnostics survive composition and dependent skipping.

Financial outputs retain explicit currency, real/nominal and tax bases, annual/horizon periods and supplied timing/rates. Shadow-price exposure is not cash; no currency conversion, new factor, physical discounting, realized saving, investment recommendation, funding, implementation, disclosure or release authority follows. Declared complete coverage does not validate source authenticity, physical reductions or economic delivery. Alternative comparisons/rankings remain evidence-conditioned screening and sensitivity, with human decisions pending.

Controlled tests and actual CLI fixtures are author-led composition evidence. They do not establish independent agent or organization acceptance, wider domain methods, source authenticity, scoped approval, roadmap closure or public-v1 readiness.
