# Source-reviewed species-mass calculation

The draft `gas-mass-0.1.0` operation in `scripts/gas_mass.py` implements explicit activity-times-factor arithmetic for one individual gas species. It supplies no built-in factor, GWP, chemical conversion, Canadian method profile or whole-facility account. Existing CO2e helpers and shared schemas remain unchanged; a separate inline factor record avoids overloading the existing CO2e emission-factor registry. This foundation extension follows approved 898d790 under continued roadmap authorization and awaits later scoped review.

## Interface and source requirements

The common CLI is `python -m scripts.run_gas_mass request.json`, using skill/operation `calculate-gas-mass`. Exact parameters are `activity_id`, `gas`, `factor`, `applicability_review`, `fixture_mode`, `result_id`. The result ID must be unused; fixture mode is explicitly boolean. This is a helper operation, not a generated individual skill.

Activity resolves to a current nonblocked result metric. Its value must be known, finite and nonnegative. The metric and review match the current organization boundary/reporting period; the period cannot postdate assessment. Selected activity evidence covers the period with matching units/boundary, source versions and nonfuture access. No missing period, negative quantity, partial operation or source context is annualized or filled. The activity value is an explicitly reviewed input; this operation does not reproduce an upstream measurement model or authenticate its source truth.

The factor is null when unavailable, or has exactly `id`, `gas`, `activity_kind`, `value`, `unit`, `source`, `method`, `geography`, `vintage_year`, `valid_period`, `status`, `evidence_ids`. Its unit is an exact `g GAS/DENOMINATOR`, `kg GAS/DENOMINATOR` or `t GAS/DENOMINATOR` compound; the numerator matches the selected individual species. The denominator uses existing supported dimensional conversions. CO2e/family numerators, unknown units, implicit heating value/density and gas-family substitution are rejected. Individual gas IDs are supplied and reviewed; a syntactically valid ID is not chemical-identity authentication.

Source fields are `locator`, `publisher`, `version`, `accessed`; method fields are `name`, `version`, `source`. Factor geography, integer vintage, species and activity kind match the explicit policy, and the declared valid period covers the activity. The factor value is finite and nonnegative, with unknown missing factors withheld. Factor evidence matches exact compound units/boundary and a source locator/version, with nonfuture accessed records. A metadata review is a caller source judgment; it does not authenticate factors, legally adopt a method or establish rights. Factor validity remains a reviewed source assertion, not a time-series measurement reproduced by this primitive.

Applicability review has `boundary_id`, `period`, `as_of_date`, `geography`, `acceptable_vintages`, `activity_kind`, `activity_review`, `factor_review`, `scope`, `reviewer_role`, `rationale`. Geography is an explicit selected basis, not inferred from jurisdiction hierarchy. `activity_kind` records the selected fuel/process context and must match the factor's context; real fuel/equipment/source applicability still requires professional interpretation.

Activity review has `metric_id`, `gas`, `activity_kind`, `value`, `unit`, `period`, `boundary_id`, `evidence_ids`, `evidence_fit`, `rationale`. It confirms the exact current activity and evidence with reviewed_supporting fitness. Factor review has `factor_id`, `activity_id`, `gas`, `activity_kind`, `source_locator`, `source_version`, `confirmed_value`, `confirmed_unit`, `evidence_ids`, `evidence_fit`, `checked_as_of`, `rationale`. Its complete source/value/unit/species/activity/evidence snapshot must match, with supporting fitness and current assessment date. This prevents reusing another activity's factor confirmation silently.

Synthetic factors require fixture mode. Outside fixture mode, factor status must be reviewed, source/method locators use HTTPS and selected fixture evidence is rejected. Relabeling a synthetic factor alone cannot permit real use. Tests and checked-in demonstrations use fictional records exclusively; no actual factor or GWP is supplied.

## Arithmetic and output

The operation converts the activity into the factor denominator, multiplies by the supplied factor and converts the resulting species mass to kilograms with the existing SI dimensional primitive. It uses 34-digit Decimal arithmetic and preserves explicit conversions. The metric unit is `kg GAS`, rather than CO2e. Factor-source, activity-source, method, boundary, period, assumptions and unquantified uncertainty are retained. Out-of-range JSON serialization produces a blocked result with no numeric metric, even if an intermediate kilogram value was representable.

`GAS_MASS_CALCULATION` retains full activity/factor/source/review snapshots and raw/output mass. `GAS_MASS_INPUTS` retains the exact request parameters for later reproduction. `gwp_applied`, `co2e_produced`, `regulatory_method_verified`, `whole_facility_coverage_verified` and `source_authenticity_verified` remain false. Missing or unsuitable factors return EMISSION_FACTOR_REQUIRED and zero metrics; unsuitable activity returns GAS_ACTIVITY_DATA_REQUIRED. Successful arithmetic remains partial with a new open professional method review, preserving all inherited factor/legal/engineering gaps and obligations.

The append-only proposal changes no earlier quantities, evidence, emission-factor registry or GHG scope references. No total, regulated threshold, authorized responsibility, filing, certification or review resolution follows from a species-mass result. Later species/GWP conversion and source-ledger composition must reproduce this complete record before use.

## Evidence and remaining work

[The fictional capture](../evaluations/sus19-gas-mass.md) records exact source/input bytes and complete sequential helper/actual CLI equality. A dimensional known-answer case uses 2 GJ and an invented 5 g CH4/GJ factor, producing 10 g or 0.01 kg CH4; 2000 MJ gives the same mass. This factor is not a real CH4 factor. Copied instructions cannot apply memorized GWPs, certify compliance or resolve reviews.

[Canadian quantification research](canada-ghgrp-quantification-research.md) remains a frozen source-fit assessment at 4f31215. This method addresses initial gas-specific factor arithmetic only. Species conversion, measured property/sampling slices, actual reference-condition transformations, source-specific substitution, statutory gas/facility/fuel/source coverage, real Canadian method profiles, qualified source interpretation and independent organization evaluation remain open. Scoped architecture/development and release review remain required; this does not close a roadmap wave or establish v1 readiness.
