# Source/species treatment ledger

`source-species-ledger-0.2.0` is a separate neutral helper in `scripts/source_species_ledger.py`. It adds supplied measured-zero observations, explicit unknown slots and source-specific include/exclude treatments without changing the original gas-mass, conversion or gas-ledger helpers. This later interface awaits scoped owner review.

Run `python -m scripts.run_source_species_ledger REQUEST.json` with the common envelope skill `build-facility-gas-ledger`. Parameters are exactly `profile_pin`, `sources`, `slots`, `coverage_review`, `fixture_mode`, `result_id`. The separately selected matrix profile requires the explicit new execution contract; original `gas-ledger-0.1.0` profiles are rejected, with no automatic migration. Byte pins use the existing bounded jurisdiction-data loader, but core logic remains jurisdiction/vendor neutral.

A profile has `id`, `version`, `execution_contract`, `synthetic`, `gases`, `basis`, `time_horizon_years`, `treatments`, `source`, `scope`, `limitations`. Every source class explicitly marks every profile species `include` or `exclude`. Treatment is caller-selected source policy, not authenticated legal interpretation. No emission factor or GWP is hard-coded in runtime. The checked-in three-species profile is fictional and does not represent the full Canadian statutory roster.

Coverage review has `facility_id`, `boundary_id`, `period`, `as_of_date`, `source_inventory_complete`, `evidence_ids`, `evidence_fit`, `scope`, `reviewer_role`, `rationale`. Facility/boundary/period must match state; primary evidence must match the selected profile source/version and assessment date. Source records have `id`, `facility_id`, `activity_id`, `activity_kind`, `source_class`, `evidence_ids`, `evidence_fit`, `rationale`. Source attribution/completeness remains declared, not authenticated.

Slots have `source_id`, `gas`, `status`, `result_id`, `metric_id`, `evidence_ids`, `evidence_fit`, `rationale`, `gwp`, `gwp_review`. Status is `converted`, `measured_zero` or `unknown`. Missing/unknown slots never become zero. Converted slots select an existing conversion result and require null `metric_id`, `gwp`, `gwp_review`; the complete current conversion, gas-mass report, metric/uncertainty/evidence lineage and source/activity/gas/basis/horizon/date context must reproduce through unchanged helpers. Shared result or quantity-evidence/species reuse cannot double-count another source.

Measured-zero slots require an explicit numeric zero kilogram-species metric, matched boundary/full period, source-bound versioned evidence and an observation period ending no later than assessment. They cannot use absence prose, a missing quantity, an unconverted CO2e metric or a future-period claim. A supplied finite species-specific GWP and exact source review are mandatory even for zero. `gwp` uses the existing conversion fields; `gwp_review` uses the existing source-review fields, with `gas_result_id` and `gas_metric_id` binding the selected direct datum result/metric. Values, units, basis, horizon, source/version/date and evidence must match. Synthetic profiles/GWPs/upstream conversions require explicit fixture opt-in. GWP failure remains `GWP_REQUIRED`; a selected missing factor remains `EMISSION_FACTOR_REQUIRED`.

Every required included or excluded slot remains visible. Excluded supported raw mass and conversion reports are retained separately; missing excluded data prevents declared completeness. Blocked conversions retain their full result and available unconverted raw result, explicitly not reproduced. Supported included CO2e is summed with 34-digit Decimal arithmetic. Unknown quantities are withheld. All-unknown/unresolved input yields blocked output without metrics. Otherwise output remains partial, even when declared profile coverage reproduces.

The original state, evidence, factors, units, periods, assumptions, uncertainty, source history and outstanding reviews survive the normal atomic proposal. Exact result-hash views address selected quantities; parent/source snapshots retain uncertainty. The combined subtotal has unquantified uncertainty rather than invented confidence bounds. A professional source/method/treatment/zero-observation review remains open.

No authenticated source/facility attribution, verified regulatory method/quantity, statutory threshold, legal exclusion or publication authority follows. This is prerequisite quantity infrastructure, not a Canada threshold binding or activation. Positive direct measured masses, a real full statutory roster/treatment/GWP profile, regulatory method/coverage fitness and independent organization acceptance remain required work. Declared profile completeness is not whole-law, whole-facility or v1 readiness. No phase or full roadmap closure follows.

## Explicit direct-mass extension

`source-species-ledger-0.3.0` adds `measured_mass` only when that execution contract is explicitly selected. Original 0.2 profiles continue to reject the new status and retain their exact previous outputs. The same request envelope/front end is used; neither profile nor caller status is implicitly migrated.

A measured-mass slot uses the existing direct-datum `result_id`, `metric_id`, `gwp`, `gwp_review` fields. It requires a finite nonnegative kilogram-species observation, source-bound matching evidence, boundary/full period, an observation period ending by assessment and exact species/source/value/unit/basis/horizon/date GWP confirmation. Negative gross mass, CO2e relabeling, future observations, unfit sources or missing/mismatched GWP are withheld. Direct measurement does not invent an activity-based emission factor; its already supplied species mass is multiplied only by the separately supplied GWP.

The raw observation and uncertainty, supplied GWP/source review and source-result byte view remain in the row. Included mass contributes its supported CO2e product; excluded mass/product remains separately visible without subtraction or loss. Profile completeness remains a declaration, source attribution/measurement authenticity remains unverified and output stays partial with professional review open. Actual statutory profiles, factor-based method applicability, Canada binding/activation, independent organization acceptance and full v1 readiness remain open. The later extension awaits scoped owner review.
