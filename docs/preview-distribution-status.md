# Draft preview distribution status

This artifact is prepared locally for owner review. It is not a public release, has no chosen project distribution license and grants no new permission to use, redistribute or sublicense content. This notice is not a substitute for a license.

The export deliberately omits framework/jurisdiction catalogs, third-party research, reference tables, raw-source archives, emission/GWP coefficients, historical captures, skill assets, Git history, funding metadata and private data. Exclusion mitigates those materials' distribution exposure; it does not resolve their rights, source currency or professional fitness in the full repository.

Included helpers and schemas are original project material selected for review. Unit arithmetic cites its source rather than reproducing standards text. Normal dependency installation is separate: no third-party runtime or library binaries are redistributed or relicensed by the archive. Owner review of authorship, reuse rights and the exact selected contents remains necessary; automated scanning cannot approve ownership or confidentiality.

Before public preview publication Jeremy must decide the project license, confirm contributor/third-party rights for the selected package, choose a private security contact and approve the exact archive and wiki content. GitHub push, visibility, wiki publication and release remain separate explicit actions. Full v1 requires the whole roadmap's evidence gates, not this package's smoke checks.
