# Explicit species-mass to CO2e conversion

The draft `gas-co2e-0.1.0` helper in `scripts/gas_conversion.py` converts one fully reproduced gas-mass metric using an explicitly supplied species-specific GWP. It has no built-in GWP, default basis/horizon, inferred gas-family value, framework adoption or jurisdiction rule. It preserves earlier raw quantities and reviews. The shared schemas, legacy CO2e helper and factor registry are unchanged. This subsequent interface awaits scoped review under continued roadmap development authorization.

## Input and reproduction

Use the common CLI `python -m scripts.run_gas_mass request.json` with operation `convert-gas-mass-to-co2e`. Exact parameters are `gas_result_id`, `gas_metric_id`, `gwp`, `conversion_review`, `fixture_mode`, `result_id`. Result IDs must be unused; fixture mode is explicitly boolean. The gas-mass operation remains available through the same CLI. No individual skill is generated by this increment.

The selected owner must be a partial `calculate-gas-mass` result with one complete input diagnostic and calculation report. Its original arguments are replayed against current state using the current helper. Complete metric values/units/period/boundary/method/calculation/uncertainty, report/source snapshots and evidence IDs must reproduce after normalizing only the verification result ID. Altered source data, input arguments, output quantities, uncertainty or lineage block conversion. An arbitrary resource mass, company CO2e metric or unsupported owner cannot substitute for this record.

The selected metric is reproduced `kg GAS`. Boundary and reporting period match current state and review. The gas-source assessment date matches the conversion assessment exactly; stale contexts require a fresh gas calculation. Synthetic upstream gas mass cannot be promoted to real conversion by relabeling the new GWP. Parent quantities and source truth are not newly authenticated by replay: reproduction verifies the declared calculation/lineage, and professional source/identity/method review remains open.

## Explicit source/basis/horizon contract

`gwp` is null when unavailable, or has exactly `id`, `gas`, `value`, `unit`, `basis`, `time_horizon_years`, `source`, `status`, `evidence_ids`. The unit is exactly `kg CO2e/kg GAS`, matching the reproduced individual species. The numeric value is finite and nonnegative; zero must be an explicitly confirmed value, never a substitute for unknown. The integer time horizon is explicitly supplied (1–1000 years), and its basis/horizon match the selection review. A label and syntactically valid horizon do not prove scientific or framework applicability. No gas lookup, family-average conversion, CO2 default or 100-year default is inferred.

GWP source has `locator`, `publisher`, `version`, `accessed`. Nonempty selected evidence matches the exact primary locator/version, ratio units and current organization boundary, with known source versions and nonfuture access. These are caller-reviewed source snapshots, not authenticated table extraction. Factor/GWP reuse rights remain separate. Outside fixture mode, status must be reviewed, the primary locator uses HTTPS, and selected fixture evidence is rejected. Checked-in demonstrations use invented values, not actual GWPs.

Conversion review has `boundary_id`, `period`, `as_of_date`, `gas`, `basis`, `time_horizon_years`, `scope`, `evidence_ids`, `evidence_fit`, `source_review`, `reviewer_role`, `rationale`. Nonempty applicability evidence has supporting fitness, matched boundary, versions and nonfuture access. It records the caller's applicability judgment rather than adopting a legal or reporting-method decision.

Source review has `gwp_id`, `gas_result_id`, `gas_metric_id`, `gas`, `value`, `unit`, `basis`, `time_horizon_years`, `source_locator`, `source_version`, `evidence_ids`, `evidence_fit`, `checked_as_of`, `rationale`. The full GWP/value/ratio/species/basis/horizon/source and selected parent-result/metric snapshot must match, with current assessment date and reviewed_supporting fitness. Another source's or metric's confirmation cannot be borrowed. New source/edition/horizon selection creates a new result; earlier outputs remain unchanged, and no migration is applied.

## Arithmetic, outputs and propagation

The helper multiplies the reproduced JSON kilogram species value by the supplied source conversion value with 34-digit Decimal arithmetic, then serializes a `kg CO2e` metric. It deliberately uses the reproduced exposed metric, retaining its rounding and unquantified uncertainty; it does not resurrect hidden precision or derive physical gas mass from a corporate subtotal. Source/parent uncertainty remains unquantified in the composed result.

`GAS_CO2E_CONVERSION` retains full raw-gas metric/report, GWP/source, applicability/source-review snapshots, numeric output and explicit flags. `GAS_CO2E_INPUTS` retains exact parameters. GWP application/CO2e-production flags are true only for an executed valid calculation. Regulatory-method, whole-facility, source-authenticity and scope-account flags remain false. No gas inventory or statutory threshold is established by a single conversion.

Missing or unsuitable conversion data returns EMISSION_FACTOR_REQUIRED with no metric. Failed complete parent reproduction returns GAS_MASS_REPRODUCTION_REQUIRED. Unsupported numeric representation returns GAS_CONVERSION_DATA_REQUIRED, with no numeric metric or inferred zero. Decimal exponent underflow is trapped in both the gas-mass and conversion helpers; JSON overflow/underflow also withholds output. The small gas-mass guard change leaves existing valid captures unchanged.

Successful outputs remain partial and add an open professional GWP-method review. All earlier factor gaps, legal/professional/engineering reviews, evidence, input quantities, assumptions and historical results survive. Scope references and the emission-factor registry remain unchanged. No owner adoption, filing, certification, compliance conclusion or review resolution follows.
